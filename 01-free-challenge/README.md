## 💡 Learning Approach

I am studying front-end development through **practice-based projects**.

Rather than only studying theory, I use each challenge to:

1. Analyze the provided design
2. Build the HTML structure
3. Create the layout with CSS
4. Add JavaScript interactions when necessary
5. Test the website on different screen sizes
6. Find and fix errors
7. Review and understand the code
8. Upload the completed project to GitHub

I also use **vibe coding as a learning tool**, but my goal is to understand the generated code rather than simply copy and use it.

## 📱 Responsive Design

Whenever possible, I aim to make each project responsive for:

* Desktop
* Tablet
* Mobile

I use CSS media queries and responsive layout techniques to adapt each project to different screen sizes.
